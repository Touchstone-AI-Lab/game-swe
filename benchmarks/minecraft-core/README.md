# Minecraft (Paper plugin) benchmark pack

This directory contains the `rhenium-minecraft-v1` catalog and the
evaluator-owned assets of the Minecraft game plugin.

- `benchmark.json` selects the `minecraft` plugin and this catalog (`pack_id: core`).
- `catalog.json` is the machine-readable catalog. Every task is a
  repository-debugging task vendored from a permissively licensed open-source
  Paper plugin at a fixed upstream commit, with the upstream fix as the
  reference solution (for a task that merges adjacent upstream fixes of one
  defect, the combined change, recorded in the task's `NOTES.md`).
- `exams/<task-id>.md` contains the public authored exam documents (English).
- `runtimes.json` binds every task to the `paper-1.21.11-132` runtime. The
  Paper server jar is not stored in this repository: the `official-download`
  provider downloads it from PaperMC during `rhenium runtime prepare`, pinned by
  URL, size and SHA-256. The runtime builder verifies the SHA-256 again and
  requires the operator's own EULA acceptance record in local Hub state
  (`packs/minecraft/core/eula.txt`) before building anything.
- `private/runtime/` is the build context of the pinned verifier base image
  (`gcb-minecraft-paper-verifier:1.21.11-132`): paperclip bootstrap, server
  configuration, the trusted `javac-build.sh` used by synthetic tasks.
- `private/harbor/harness/` holds the GcbHarness Paper plugin (Java sources
  compiled into the base image), the trusted `verify.py`, and the Dockerfile
  templates from which every task package is generated.
- `private/harbor/<task-id>/` is the task's [Harbor 1.4 package](private/harbor/README.md),
  generated by `private/harbor/scripts/materialize.py` except for the vendored
  starter (`environment/plugin/`), the hidden grader suite (`tests/suite/`),
  the reference fix (`solution/after/`), `NOTES.md` and `validation/`.

The pack is read-only. Generated public manifests, starter workspaces, runtime
caches and evaluator images live under `.rhenium/`, outside this directory. The
verifier images contain Mojang server code and are never pushed to a registry.

Supported versions, platforms, evaluation layers and limitations are documented
in [Minecraft benchmark support](../../docs/games/minecraft.md).
