# Mindustry benchmark pack

This directory contains the `rhenium-mindustry-v2` catalog and the evaluator-owned assets
of the Mindustry game plugin.

- `benchmark.json` selects the `mindustry` plugin and this catalog (`pack_id: mindustry-core`).
- `catalog.json` is the machine-readable catalog. Every task is a repository-debugging
  (repair) task on the open-source Mindustry v159.7 game sources (GPL-3.0) with real
  upstream defects; the reference solution is the upstream fix.
- `exams/<task-id>.md` contains the public, symptom-only exams (English).
- `runtimes.json` binds every task to the `mindustry-159.7` runtime. The server jar is
  not stored in this repository: the `official-download` provider downloads it from the
  v159.7 GitHub release during `rhenium runtime prepare`, pinned by URL, size and
  SHA-256, and the runtime builder verifies the SHA-256 again before building anything.
- `private/runtime/` is the build context of the pinned verifier base image
  (`rhenium-mindustry-verifier:159.7`): the digest-pinned JDK 17 Dockerfile, the
  bootstrap that compiles the harness and boots the server once, and the grader
  packaging script.
- `private/harbor/harness/` holds the trusted Rhenium harness plugin (Java sources
  compiled into the base image), the trusted `verify.py`, and the Dockerfile templates
  from which every task package is generated.
- `private/harbor/<task-id>/` is the task's [Harbor 1.4 package](private/harbor/README.md),
  generated by `private/harbor/scripts/materialize.py` except for the vendored starter
  (`environment/mindustry/`), the hidden grader suite (`tests/suite/`), the reference fix
  (`solution/after/`), `NOTES.md` and `validation/`.
- `private/study-controls/<task-id>/` holds the E0 control material (clause map,
  control patches and trees, notes).

The pack is read-only. Generated public manifests, starter workspaces, runtime caches
and evaluator images live under `.rhenium/`, outside this directory. The verifier images
contain the Mindustry server and are never pushed to a registry.

Supported versions, platforms, evaluation layers and limitations are documented in
[Mindustry benchmark support](../../docs/games/mindustry.md).
