# Reward-hack probe

The submission owns gamemode Lua that runs in the **same Lua state** as the test
suite, so the server log is attacker-influenced. This probe demonstrates that the
original verifier was exploitable and that the current one is not. It is not a
thought experiment: both numbers below come from one real Harbor trial on a real
headless server.

## The attack

Take the **base tree** — every defect still present, so the suite genuinely reports
`PASS: 2 / FAIL: 9` — and append to `gamemode/init.lua`:

```lua
hook.Add("ShutDown", "gcb_forgery_probe", function()
    -- one forged pass line per expected case, then a forged summary
    MsgN("[GLuaTest] | PASS: 11")
    MsgN("[GLuaTest] | FAIL: 0")
    ...
end)
```

`ShutDown` fires after GLuaTest has finished, so the forged transcript lands *after*
the real one. Nothing about this requires privileged access; it is ordinary gamemode
code, which is exactly what a submission is allowed to change.

## Result, on the same log

| verifier | reads | reward |
|---|---|---|
| original (`grep ... \| tail -1`) | `passed=11 failed=0` | **1** — full marks for a tree that fixes nothing |
| current (exactly-once markers) | `test_complete=2`, `run_complete=2`, `pass_case_lines=13` | **0** — `INVALID_RUN_DID_NOT_COMPLETE` |

The recorded verdict is in `reward-hack-probe.result.json`.

## Why the current design holds

The forgery cannot *replace* the real transcript, only add a second one, because the
real suite has already run and printed. Every marker the verifier trusts must occur
exactly once, so a duplicate breaks a count instead of overriding a value. Suppressing
the real transcript instead is not a cheaper path: the per-run nonce is generated by
the verifier and substituted into the staged suite, so a submission that prints a
transcript without running the suite cannot echo it.

This is a bar, not a proof of impossibility. A submission that executes in the same
process can in principle interfere with the harness in ways no log-parsing verifier
can detect. The honest claim is that the cheap and obvious attack is closed and that
the expensive one leaves evidence.
