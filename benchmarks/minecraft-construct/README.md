# Minecraft (Paper plugin) construct pack

This directory contains version 1.3.0 of the `rhenium-minecraft-construct-v1` catalog of the Minecraft game
plugin: five construct tasks in which the model writes a whole Paper server plugin from a
skeleton, graded by hidden cases on a real Paper 1.21.11 dedicated server.

- `benchmark.json` selects the `minecraft` plugin and this catalog (`pack_id: construct`).
- `catalog.json` is the machine-readable catalog. Every task has `task_kind: construct`, no
  upstream repository and the frozen Maven build of its skeleton.
- `exams/<task-id>.md` are the public exams (English). They state every reply line, file format
  and validation order that a hidden case asserts.
- `runtimes.json` binds every task to its own runtime id, `paper-1.21.11-132-construct`. It
  downloads the same pinned Paper jar as `minecraft-core` through the `official-download`
  provider (URL, size and SHA-256 pinned) and needs the operator's own EULA acceptance record
  for this pack (`packs/minecraft/construct/eula.txt` in local Hub state); the runtime key is
  separate because a runtime key names exactly one pack.
- `private/runtime/` and `private/harbor/harness/` originate from the `minecraft-core` runtime
  and GcbHarness. This pack's build templates use Huawei Cloud mirrors for Maven Central and the
  pinned Maven distribution; the distribution's SHA-512 check remains enabled, the PaperMC API
  repository is unchanged, and evaluation runs without network access.
- `private/harbor/<task-id>/` is the task's [Harbor 1.4 package](private/harbor/README.md),
  generated by `private/harbor/scripts/materialize.py` except for the skeleton
  (`environment/plugin/`), the hidden suite (`tests/suite/`), the reference plugin
  (`solution/after/`), `NOTES.md` and `validation/`.
- `private/study-controls/<task-id>/` holds the E0 controls: the clause map, a target-negative
  patch, an independently written alternative plugin and the observed outcomes.

The pack is read-only. Starter workspaces, runtime caches and evaluator images live under
`.rhenium/`. The verifier images contain Mojang server code and are never pushed to a registry.

| Task | Plugin | Server cases |
| --- | --- | --- |
| `coinledger-bank-ledger` | CoinLedger: transfer preflight with combined-credit validation when recipient aliases the fee account | 30 |
| `blocktrail-block-log-rollback` | BlockTrail: backward-compatible change logs that preserve directional block data through guarded rollback | 27 |
| `towncrier-timed-announcements` | TownCrier: independent group timers, message cycles and permissions | 20 |
| `wardstone-region-protection` | Wardstone: priority-resolved flags enforced on block changes, explosions, fire, and destination-side liquid flow | 27 |
| `recipesmith-config-recipes` | Recipesmith: validated shaped and shapeless recipes with per-player craft permissions, alongside cooking and stonecutting | 18 |

Supported versions, evaluation layers, validation records and limitations are documented in
[Minecraft benchmark support](../../docs/games/minecraft.md).
