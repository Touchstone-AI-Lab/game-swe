# Fargo's Souls toggle source projection

This source-only snapshot retains the production toggle registry, backend,
preset, and lookup code from Fargo's Souls Mod 1.7.3.7. Terraria, tModLoader,
XNA, localization, preference, and unrelated accessory-effect classes are
represented by compile-time projection stubs.

Run `python3 tools/smoke.py` for the public compile check. It performs no
behavioral evaluation.
