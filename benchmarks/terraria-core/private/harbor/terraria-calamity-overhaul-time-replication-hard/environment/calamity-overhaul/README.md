# Calamity Overhaul time-replication source projection

This source-only snapshot retains the production network entity identities and
time-control replication system from Calamity Overhaul 0.9209. Terraria,
tModLoader, logging, time-freeze generation, and late-join subsystem providers
are represented by compile-time projection stubs.

Run `python3 tools/smoke.py` for the public compile check. It performs no
behavioral evaluation.
