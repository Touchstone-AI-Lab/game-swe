These are self-authored fixtures, scenarios, oracles, contracts and known controls
copied byte-for-byte from the frozen local Balatro PoC v0.2. They are deliberately
constructed repair tasks, not claims of real upstream historical bugs.

`assets.json` records the original 501-file freeze identity, original task and
candidate fingerprints, copied file hashes, required cases and process counts.
All 350 copied files were verified against that source freeze before import.
The accompanying original public release remains unchanged. No game, third-party
dependency, save, `.state`, runtime log or personal data is included here.

These assets are maintenance-only. They must not be copied into public attempts,
public task ZIPs or wheels. Plugin wheels contain only the adapter package; the
operator supplies this private benchmark pack independently. Preserve the source
metadata and any original attribution. No additional third-party license grant
or ownership identity is inferred. Maintainer supplied by the user: Sangyu Pan.

Process counts describe the frozen scenario's full lifecycle and were crosschecked
against its historical hash-bound results. Those old results do not constitute
new Rhenium platform verification. New results belong only in platform state.
