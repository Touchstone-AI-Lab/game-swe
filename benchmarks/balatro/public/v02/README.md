# Balatro-10 v0.2

Ten authored repair exercises: 3 easy, 4 medium, 3 hard. These are unmeasured design labels, not model pass rates. See INDEX.json and each task's CONTRACT.md, README.md and package.json. Only each package's explicit starter Lua allowlist is editable; its manifest is fixed.

Operator tooling uses protocol v2 to export, seal and score reviewed submissions in the fixed licensed Windows desktop environment. This archive contains participant materials only, without private evaluation code, reference solutions, logs, saves, game/dependency contents or user data. It does not claim a hostile-code sandbox or formal Rhenium integration.
