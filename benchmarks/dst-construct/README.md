# Don't Starve Together benchmark pack

This directory contains the DST catalog and evaluator-owned assets.

- `benchmark.json` selects the `dst` plugin and catalog.
- `fixed-v1.json` is the machine-readable v2 catalog; its stable filename is
  retained for packaging compatibility.
- `exams/<task-id>.md` contains the public authored exam documents.
- `hidden/<task-id>.lua` contains sandboxed plain-Lua behavioral assertions.
- `server/<task-id>.lua` contains private headless dedicated-server assertions.
- `runtimes.json` binds every task to the managed
  `dst-dedicated-24700372-construct` container runtime.
- `private/runtime/dst-harbor-runtime/` is the build context of the pinned
  dedicated-server verifier image.
- `private/harbor/<task-id>/` is the task's [Harbor 1.4 package](private/harbor/README.md),
  generated by `private/harbor/scripts/materialize.py` except for its hand-written
  `solution/reference/`.

The pack is read-only. Generated public manifests and starter workspaces live
under `.rhenium/hub/packs/dst/construct/`, outside this directory.

Each Harbor package carries one reference mod under `solution/reference/`. It is a
validation gold control: it proves every assertion is satisfiable on the pinned
server and never participates in scoring. A model run receives only the public
task contract and verified base-game API signatures. References, hidden
assertions and evaluator internals are never copied into an attempt or a model
workspace.

This pack holds the ten construct tasks of catalog `rhenium-dst-v2` 2.1.0. They
were the `dst/core` pack in `benchmarks/dst/` until the repair pack replaced
them there, and were restored here unchanged under the pack ID `construct`
(task keys `dst/construct/<task-id>`). Only paths and keys that name the pack
moved: the materialize script, the `content_reference` of each `task.toml`, and
the `task` and `exam` fields of each `private/study-controls/<task>/clause-map.json`.
The study-control notes and the older validation evidence are historical and
still name `benchmarks/dst/`, `dst/core/<task-id>` and the
`dst/dst-dedicated-24700372` runtime that the tasks used before the move.

Supported versions, platforms, languages, ownership, and runtime limitations
are documented in [DST benchmark support](../../docs/games/dst.md).
